# Servlets Project

## English
This repository contains a Java web project focused on servlet development. It uses Maven for project management and is organized around the `src` directory and the main configuration file `pom.xml`.

The project is intended to practice server-side Java development, HTTP request handling, and web application structure with Tomcat-based deployments.

### Project components
- `src`: source code for the application
- `pom.xml`: Maven configuration
- `.idea` and `.smarttomcat`: IDE and local runtime configuration
- `.gitignore`: ignored files

## Español
Este repositorio contiene un proyecto web en Java centrado en el desarrollo de servlets. Utiliza Maven para la gestión del proyecto y está organizado alrededor del directorio `src` y del archivo de configuración principal `pom.xml`.

El proyecto está pensado para practicar el desarrollo Java del lado del servidor, el manejo de peticiones HTTP y la estructura de aplicaciones web con despliegues basados en Tomcat.

### Componentes del proyecto
- `src`: código fuente de la aplicación
- `pom.xml`: configuración de Maven
- `.idea` y `.smarttomcat`: configuración del IDE y del entorno local
- `.gitignore`: archivos ignorados
